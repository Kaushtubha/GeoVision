# 🧪 GeoVision Experiments & Tracking

This directory contains local experiment outputs, configuration overrides, and tracking artifacts generated during model evaluation and training runs.

## Structure

- `configs/`: Experiment-specific configuration overrides (e.g., hyperparameter tuning or dataset ablation configs).
- `runs/`: (Gitignored) Local artifacts generated by training and evaluation CLIs.
- `visualizations/`: (Gitignored) Generated tri-panel change overlays, segmentation masks, and bounding box visualizations.

## MLflow Experiment Tracking

To log runs to a centralized or local MLflow tracking server:

```bash
# Start local MLflow server
mlflow server --backend-store-uri sqlite:///mlflow.db --default-artifact-root ./mlruns --port 5000

# Configure environment
export MLFLOW_TRACKING_URI=http://localhost:5000
```

When `tracking.enabled: true` in `configs/tracking.yaml`, metrics (loss, mAP, mIoU, Recall@K) and parameters are tracked automatically. If MLflow is unreachable, the system automatically falls back to offline tracking without raising unhandled exceptions.
